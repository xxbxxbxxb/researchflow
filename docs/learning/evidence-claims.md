# 资料与结论

PDF是来源，保存的canonical page是定位基础，Chunk用于检索，Evidence绑定页码、起止和quote_hash。引用必须回到同一个保存字符串，不用后来变化的网页或解析换行猜位置。

Claim是原子事实，提出候选引用；Verifier分别检查身份/项目、位置和语义支持。合法ID不会让样本12人的原文支持样本999人的结论。数值、单位和条件规则还能把模型判断限制为inconclusive。

supported/contradicted/insufficient/inconclusive分别表示支持、反驳、不足和验证不确定。报告只把supported放进结论，其他判断仍留在发现区。完整材料不足报告可成功执行，不等于得到了可靠事实。

人工接受创建有来源的知识记录。改判和取代追加历史与原因。后续知识只作为项目数据，仍按当前证据重新验证，不能成为不可质疑的系统指令。

实验：先改一个offset触发完整性失败，再保留合法引用但改错Claim数字，观察语义受限。这两种失败不能混为一谈。
